# AI 단체방

여러 무료 AI와 폰 안의 로컬 AI가 한 방에서 같이 대화하는 안드로이드 앱입니다.

## APK 만들기 (하루 블록 때와 같은 방식)
1. GitHub에 새 저장소를 만들고 이 폴더의 **모든 파일**(숨김 폴더 `.github` 포함)을 올립니다.
2. 저장소의 **Actions → Build APK → Run workflow** 를 누릅니다.
3. 끝나면 **ai-group-chat-apk** 를 내려받아 압축을 풀고 `app-debug.apk` 를 폰에 설치합니다.

## 처음 실행
1. 앱의 ⚙ 설정에서 키를 입력합니다 (NVIDIA / Groq / OpenRouter). 키는 폰 안에만 저장됩니다.
2. 카드마다 **연결 테스트**를 눌러 ✓ 가 뜨는지 확인합니다.
3. 모델 이름이 안 맞으면 **목록**을 눌러 고릅니다. (무료 모델 목록은 자주 바뀝니다)

## 대화 방법
- 그냥 말하면 모두 답합니다.
- `딥이야 이거 뭐야?` · `@딥이 …` · `딥이랑 로컬은 어떻게 생각해?` → 부른 AI만 답합니다.
- `방금 딥이 말에 대해 어떻게 생각해?` → 이름을 *언급*만 하면 모두 답합니다.
- 별명은 설정에서 AI마다 여러 개 지을 수 있고, 같은 별명을 두 AI에 쓸 수는 없습니다.
- `기억해: …` → 모든 AI가 공유하는 기억에 저장. `/잊어 …`, `/기억목록` 도 됩니다.

## 로컬 AI (인터넷 없이)
앱은 폰 안에서 도는 **OpenAI 호환 서버**에 연결합니다 (기본 `http://127.0.0.1:11434/v1`).
Termux 예시 (패키지 이름은 Termux 버전에 따라 다를 수 있습니다):

```
pkg install ollama
ollama serve &
ollama pull qwen2.5:3b
```

다른 서버(llama.cpp의 `llama-server` 등)를 쓰면 설정에서 로컬 카드의 **주소**와 **모델**을 바꾸세요.
인터넷이 되면 로컬 AI는 검색해서 읽고 종합해 답하고, 안 되면 아는 것과 기억만으로 답합니다.

## 한계
- 모델 자체를 폰에서 실시간으로 다시 학습시키지는 않습니다. 대신 `기억` 방식으로 바로 반영됩니다.
- 무료 API는 한도가 있습니다. 한도에 걸리면 상태 표시줄에 안내가 뜨고 한 번 자동 재시도합니다.
